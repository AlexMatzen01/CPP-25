## 🔧 Building the Project

### Prerequisites
- C++17 compatible compiler (GCC 7+, Clang 5+, MSVC 2017+)
- CMake 3.10+ (for CMake build) OR GNU Make
- Terminal with ANSI color support (for best visual experience)

### Option 1: Using CMake

```bash
# Create build directory
mkdir build && cd build

# Generate build files
cmake ..

# Build
cmake --build .

# Run
./bin/AdventureQuestEngine
```

### Option 2: Using Makefile

```bash
# Build release version
make release

# Or build with debug symbols
make debug

# Run
make run

# Clean
make clean
```

### Option 3: Quick Compile (Linux/macOS/WSL)

```bash
g++ -std=c++17 -O3 main.cpp src/*.cpp -Iinclude -o game
./game
```

## How to Play

### Starting the Game
1. Run the executable
2. Choose "New Game" from the main menu
3. Create your character (name and class)
4. Begin your adventure!

### Commands
- **Movement**: `n`, `s`, `e`, `w` (or `north`, `south`, `east`, `west`)
- **Actions**: 
  - `look` - Examine the current room
  - `search` - Search for hidden items
  - `interact` - Interact with room objects
  - `pickup [#]` - Pick up an item
- **Menus**:
  - `inventory` - Open inventory
  - `status` - View character stats
  - `quests` - View quest log
  - `map` - View dungeon map
  - `help` - Show command list
- **Other**:
  - `save` - Save your game
  - `menu` - Open game menu
  - `quit` - Exit game

### Character Classes

**Warrior**
- High HP and Attack
- Excels in direct combat
- Best for beginners

**Mage**
- High Magic Power
- Fragile but powerful spells
- Requires strategic play

**Rogue**
- High Critical Hit and Dodge
- Nimble and evasive
- Rewards skillful play

**Paladin**
- Balanced stats
- Self-healing abilities
- Versatile for any situation

### Tips
- Search rooms thoroughly for hidden items
- Save your game regularly
- Choose your battles wisely
- Explore all areas for secrets
- Pay attention to your choices - they affect the ending!

## Development

### Architecture
- **GameEngine**: Coordinates all game systems
- **MapGenerator**: Procedurally generates dungeons
- **CombatSystem**: Manages turn-based combat
- **EventSystem**: Handles story events and choices
- **InventorySystem**: Manages items and equipment
- **FileIO**: Handles save/load and data files

### Key Design Patterns
- **Singleton-like Game State**: Centralized game state management
- **Component-Based Entities**: Flexible entity design
- **Template Method**: Consistent system interfaces
- **Strategy Pattern**: Different combat behaviors

### Extending the Game
To add new content:
1. **New Enemies**: Add to enemy templates in Types.h
2. **New Items**: Add to item templates
3. **New Events**: Create event structures in Events system
4. **New Room Types**: Extend RoomType enum and generation logic
